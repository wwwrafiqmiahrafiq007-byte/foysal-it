# Contributing

## Branches

- `main` — production
- `develop` — integration
- `feature/*` — features
- `fix/*` — bug fixes
- `chore/*` — maintenance

## Pull requests

Every PR should explain what changed, why, how it was tested, security/data implications, and any migration or environment-variable changes.

Do not merge with failing lint, typecheck, build or required security checks.

Never commit secrets or real customer data.
